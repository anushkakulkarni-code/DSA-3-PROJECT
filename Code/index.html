This application demonstrates how Data Structures and Algorithms concepts can solve computational biology problems. Global alignment compares both sequences from beginning to end, using match scores, mismatch penalties, and gap penalties.

LEARN THE METHOD

How it works

The Needleman–Wunsch algorithm finds an optimal global alignment using dynamic programming.

Algorithm steps

  1. Enter Sequence 1 and Sequence 2
  2. Set match, mismatch and gap scores
  3. Initialize the dynamic programming matrix
  4. Fill the matrix using the best score at each cell
  5. Trace back from the bottom-right cell
  6. Generate the optimal alignment
  7. Calculate and display the score

The recurrence

Each cell takes the best of three moves: a diagonal step (match or mismatch), a step from above, or a step from the left (gap).

F(i,j) = max( F(i-1,j-1) + s(ai,bj),
             F(i-1,j) + gap,
             F(i,j-1) + gap )

The first row and column start at multiples of the gap penalty. Because global alignment covers both complete sequences, the final score is in the bottom-right cell.

Complexity

Time: O(mn)   Space: O(mn)

Here, m and n are the lengths of the two input sequences.
